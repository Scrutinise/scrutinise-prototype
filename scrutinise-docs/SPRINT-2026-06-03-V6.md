## PART 2 — FCA Handbook: sitemap investigation

### Context
FCA Handbook is a JS SPA — the navigation shell is JS-rendered, but individual
rule pages may have their text in the initial HTML response (many SPAs do this
for SEO). The sitemap approach is viable if:
(a) A usable sitemap exists listing all rule page URLs, AND
(b) Individual rule pages return text content in the initial HTML

### Step 1 — Check sitemap
```typescript
// Try standard sitemap locations
const sitemaps = [
  'https://www.handbook.fca.org.uk/sitemap.xml',
  'https://www.handbook.fca.org.uk/sitemap_index.xml',
  'https://handbook.fca.org.uk/sitemap.xml',
]
for (const url of sitemaps) {
  const res = await fetch(url)
  console.log(url, '→', res.status, res.headers.get('content-type'))
  if (res.ok) {
    const text = await res.text()
    console.log('first 500 chars:', text.slice(0, 500))
    // Count <loc> entries
    const locs = text.match(/<loc>/g)?.length ?? 0
    console.log('URL count:', locs)
  }
}
```

## PART 3 — lda.data.parliament.uk API integration

### Context
`explore.data.parliament.uk` exposes a linked data API at `lda.data.parliament.uk`
with no authentication, JSON format, up to 500 records per page.
Datasets available: Hansard Commons Documents, Hansard Lords Documents,
Commons Written Questions, Lords Written Questions, Lords Bill Amendments,
Commons Oral Questions, Committee hearings, and more.

This API was not blocked in V5 testing and replaces the need for TWFY for some
sources. Use TWFY for Hansard speech text (debates); use LDA for structured data
(voting records, oral questions, committee proceedings, bill amendments).

### Step 3 — Build lda-parliament.ts source client

For each confirmed working dataset, build paginated fetcher:
```typescript
// scripts/ingest/sources/lda-parliament.ts
// lda.data.parliament.uk — Linked Data API, no auth required
// Max 500 records/page, pagination via _page param

export async function fetchLdaDataset(
  slug: string,
  page: number,
  pageSize: number = 500
): Promise<{ items: any[], totalResults: number }> {
  const url = `https://lda.data.parliament.uk/${slug}.json?_pageSize=${pageSize}&_page=${page}`
  const res = await fetch(url)
  if (!res.ok) throw new Error(`LDA ${slug} page ${page}: HTTP ${res.status}`)
  const data = await res.json()
  return {
    items: data.result?.items ?? [],
    totalResults: data.result?.totalResults ?? 0
  }
}

// Convert LDA item to compiledText
// Each dataset has different fields — handle the main ones:
export function ldaItemToText(item: any, datasetType: string): string {
  switch (datasetType) {
    case 'hansard':
      return [item.title, item.text, item.memberPrinted?.label].filter(Boolean).join('\n\n')
    case 'oral-questions':
      return [item.title, item.answerText, item.questionText].filter(Boolean).join('\n\n')
    case 'written-questions':
      return [item.title, item.answerText, item.questionText, item.answer?.label].filter(Boolean).join('\n\n')
    default:
      return JSON.stringify(item)
  }
}
```
