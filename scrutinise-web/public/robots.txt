# Scrutinise — robots.txt
#
# PRINCIPLE 7 (The National Archives computational analysis licence): judgment and decision text
# must not be indexed by search engines, and third-party crawling of the records — or of data
# extracted from them — must be prevented so far as we can.
#
# There is no judgment page on this site. Judgment text reaches a reader only as a short extract
# inside an idea, so /ideas/ is the surface that rule is about, together with the public JSON reads
# under /api/ that serve the same content.
#
# A Disallow is a REQUEST, not a control. The controls are the `X-Robots-Tag` header (next.config.js)
# and the `<meta name="robots">` tag (app/ideas/layout.tsx), which apply to a crawler that fetches
# anyway. All three are deliberate: a crawler may honour any one of them and ignore the others.
#
# ⚠ Note the interaction, stated rather than assumed: a path disallowed here is not fetched, so a
# well-behaved crawler never reads the noindex on it. That is the right order for pages that are
# NOT currently indexed — checked 2026-08-27, no idea page appears in any search result — because
# it prevents the first crawl rather than asking for a later removal. If a page ever DOES appear in
# an index, remove its Disallow temporarily so the crawler can see the noindex and drop it.
