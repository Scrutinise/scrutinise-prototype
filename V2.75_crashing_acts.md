# V2.75-I Phase 1 — Ingest Diagnostic Report

**Date:** 2026-04-30  
**Analyst:** Claude Code  

## Symptom
After 12 hours and 7 PM2 restarts, `ingest-checkpoint.json` showed 11,768/12,009 acts.
PM2 process `scrutinise-ingest` was running but making no progress.

## Diagnosis

### Root Cause A — Corpus was already fully ingested

Log analysis of `pm2-ingest-out.log` (32.8 MB) revealed:

- Last real act-processing run: **Apr 29 03:52–03:59**
- Final act logged: `[12011/12009] ukpga/1801/52 ✓ 5 sections` at **03:59:32**
- Next line: `Fetching feed page 1` at **03:59:38** (PM2 restarted 6s after clean exit)
- All 17+ subsequent restarts are idle loops through a completed corpus

**The full corpus of 12,012 acts was ingested on Apr 29 at 03:59. The process was NOT crashing.**

### Root Cause B — PM2 autorestart on clean exit code 0

`ecosystem.config.js` had `autorestart: true` with no `stop_exit_codes` exclusion.  
PM2 treats exit code 0 (clean completion) the same as a crash — it restarts unconditionally.

### Root Cause C — 100-minute skip loop per restart

The main loop iterated over ALL `acts` (12,009) with a 500ms inter-act delay, even for  
acts already in the checkpoint. Each restart: ~60s feed fetch + ~100min skip loop = ~1h45min  
before the process exits cleanly, triggering another restart.

### Why checkpoint showed only 11,768 (not 12,009)

`completed.add(id)` and `saveCheckpoint()` are called in the main loop — which now iterates  
`remaining` not `acts`. On the final full run (initial checkpoint ≈ 3 acts), PM2 restarted  
mid-save during one of the earlier runs, leaving the checkpoint at 11,768.  
The 241 remaining acts were processed in the 03:52–03:59 run but were zero-section or  
short acts; the checkpoint file was last written at 11,768 before a mid-run restart wiped it.

## Error Log Findings

`pm2-ingest-error.log` contained only benign warnings from the 03:16–03:59 run:
- `200 but no matching P1group` — pre-CLML acts (pre-1987), no section XML available
- `HTTP 301` — old range-numbered sections (e.g. `s.1-3`)

**No fatal errors. No crashes. No unhandled exceptions.**

## Fixes Applied (Phase 2)

| Fix | Change |
|-----|--------|
| PM2 autorestart on clean exit | `stop_exit_codes: [0]` added to ecosystem.config.js |
| 100-min skip loop | Main loop now iterates `remaining` (not `acts`) — skips 500ms delay for done acts |
| Completion detection | If `remaining.length === 0`, logs "Corpus complete" and exits cleanly |
| Checkpoint format | Added `permanentlySkipped` and `attemptCounts` fields |
| Attempt tracking | Acts failing ≥ 3 times → `permanentlySkipped`, logged to V2.75_crash_log.md |
| Crash exit code | `main().catch()` now calls `process.exit(1)` — PM2 will restart on genuine crash |
